# Aashi Documentation

## Contents

- `specifications/` — the authoritative Aashi specifications (Architecture,
  UI/UX, module contracts, roadmap). Place the approved documents here; they are
  the source of truth and override anything written elsewhere in this folder.
- `modules/` — one record per completed module: what it implements, its public
  interface, its configuration and its design decisions.

| Module | Title | Record |
| --- | --- | --- |
| UI-01 | Project Foundation | [modules/UI-01-foundation.md](modules/UI-01-foundation.md) |

## Conventions

- Documentation is updated in the same change as the code it describes.
- A module record is written when the module is completed, not planned.
- Where documentation and an approved specification disagree, the specification
  wins and the documentation is corrected.
