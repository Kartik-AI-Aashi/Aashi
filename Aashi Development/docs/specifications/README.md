# Aashi Specifications

The authoritative Aashi specifications belong in this directory:

- Aashi Software Requirements
- Aashi Software Architecture
- Aashi UI/UX Specification
- Module contracts
- Development roadmap
- Coding standards

These documents are the source of truth. Where implementation or other
documentation disagrees with an approved specification, the specification wins.

> **Note:** UI-01 was implemented from the module brief because these documents
> were not yet present in the repository. Add them here, and UI-01 should be
> reviewed against them before UI-02 builds on top of it.
